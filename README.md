# 筑序 · 施工效率驾驶舱（正式演示版）

面向项目经理、生产经理和现场管理人员的施工全过程效率管理系统。当前交付为可直接运行、可完整演示业务闭环的本地正式演示版。

## 当前能力

- 提供独立登录页、登录会话、保持登录和安全退出；账号与组织架构人员、岗位权限绑定。
- 材料审批只允许当前节点指定本人操作，其他账号可查看进度但不能代办；审批操作记录账号和时间。
- 项目首页维护组织架构，以账号职位作为责任匹配依据，不依赖固定人名。
- 进度计划分为总计划、月计划、周计划、日计划；支持新建、修改和导入后更新。
- 计划导入支持 Excel、Word、PDF、图片、CSV 和 TXT，并在写入前提供可编辑的识别结果。
- 任务支持手工录入、文件识别和语音转文字；系统按任务内容匹配岗位与责任人，且可人工修正。
- 所有任务均可编辑，也可按紧急或一般级别催办影响本任务的前置工序。
- 现场记录支持拍照或从相册选择多张照片，压缩后持久保存到浏览器本地数据库。
- 材料和设备分开管理，并分别登记名称、分类、品牌、规格、进出场时间、数量、使用部位和附件。
- 材料按类别汇总；合格证、见证取样和验收照片可随进场记录保存。
- 材料进场后自动通知资料员，并生成“是否取样送检、是否留存合格证”的待办事项。
- 材料与设备计划可单独新建，记录需求日期、数量、责任岗位和状态。
- 材料设备计划责任岗位从项目组织架构读取，覆盖施工员、质量员、材料员、试验员等岗位。
- 材料设备计划在要求到场前 7 天自动进入预报，临近或逾期未到场时分级提示。
- 台账登记可自动推荐或人工指定关联计划；分批到场会累计已到数量，并实时计算剩余数量。
- 材料、设备台账及计划清单均可点击查看完整详情和关联到场记录。
- 材料设备附件原文件保存到浏览器附件库；图片可直接预览，PDF可在线打开，其他文件可下载查看。
- 资料完成情况与施工进度关联，覆盖钢筋、混凝土和防水工程资料链及工序放行。
- 所有材料进场批次都会生成对应资料链，自动带入品牌、规格、数量和使用部位。
- 资料任务可查看编辑，分别保存送检委托和检测报告，并记录待送检、检测中、合格或不合格状态。
- 质量与安全检查支持编辑、巡检表上传、整改前后照片和复验闭环，统计卡片可展开具体内容。
- 组织架构页记录项目管理人员姓名、职务、管理范围及电话；现场人数由劳资员上传每日实名制考勤表更新。
- 全局“新建任务”只在总览显示，其他页面保留各自的业务操作入口。
- 二级页面提供固定返回按钮，适配桌面、平板和手机屏幕。
- 支持晨会简报、效率建议和项目 JSON 数据导出。

## 文件识别说明

- DOCX、XLSX、CSV、TXT：在浏览器本地解析，可形成多条可编辑任务或计划。
- PDF：当前原型使用本地文本特征提取，复杂排版或扫描件需要人工校对。
- 图片：浏览器支持原生文字检测时会直接识别；不支持时生成待校对候选项。
- 语音：浏览器支持语音识别且授予麦克风权限时可直接转文字，也可粘贴转写稿后解析。

生产环境若要求稳定识别扫描 PDF、施工计划照片和嘈杂现场语音，建议接入企业 OCR、语音识别及大模型结构化服务。

## 运行方式

### 项目局域网多人试用（推荐）

1. 在作为项目服务器的电脑上双击 `启动局域网版.cmd`。
2. Windows 防火墙首次询问时，允许 Node.js 访问“专用网络”。
3. 启动窗口会显示本机和局域网登录地址。
4. 本机访问 `http://127.0.0.1:8080`；同一 Wi-Fi/局域网中的其他设备访问 `http://服务器电脑IP:8080`。
5. 当前电脑的 WLAN 地址示例为 `http://192.168.1.6:8080`，地址变化时以启动窗口显示为准。

多人版数据保存在 `data/zhuxu-lan.sqlite`，请定期备份该文件。关闭启动窗口或按 `Ctrl+C` 会停止服务，作为服务器的电脑需要保持开机和联网。

多人版当前共享任务、计划、材料设备台账元数据、资料状态、审批流程、质量安全、组织架构和考勤数据；服务器同时校验登录会话与材料审批权限。现场照片和部分大附件仍保存在上传者浏览器本机，下一阶段接入服务器文件库后可跨设备查看原件。

### 本机离线演示

直接使用浏览器打开 `index.html`，无需启动服务。该模式的数据只保存在当前浏览器中，不与其他人同步。

若只需临时静态预览，可在此目录启动静态文件服务：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 开发基线

### 环境要求

- Windows 10/11；
- Node.js 24 或更高版本（服务端使用内置 `node:sqlite`）；
- npm；
- Google Chrome，默认安装位置为 `C:\Program Files\Google\Chrome\Application\chrome.exe`。

首次获取代码后安装锁定版本的开发依赖：

```powershell
npm ci
```

启动局域网服务：

```powershell
npm start
```

运行完整开发基线检查：

```powershell
npm test
```

完整检查包含 JavaScript 语法、桌面和移动端离线流程、材料审批与隐蔽验收，以及局域网多账号登录、共享状态和服务端审批权限。局域网测试会自动创建并清理独立的临时数据库，不会改动 `data/zhuxu-lan.sqlite`。

测试生成的 `qa-*.png` 截图、`node_modules/`、npm 缓存、运行数据库和上传附件均已加入 `.gitignore`。切换 ChatGPT、Codex 或 DeepSeek 前，应更新 [HANDOFF.md](HANDOFF.md)，并只交接项目文件、普通文本和稳定 JSON，不传递供应商原始响应对象。

## 登录说明

- 登录账号取自“组织架构”中的账号字段。
- 初始密码为该人员登记手机号的后六位。
- 示例：项目经理陈海峰账号 `chen.pm`，初始密码 `001001`。
- 左侧栏底部可退出当前账号；退出后必须重新输入账号和密码登录。

本地正式演示版的密码校验和数据保存在浏览器本机，用于业务确认与现场演示。正式多人联网部署必须由服务端完成密码哈希、会话管理、权限校验和审计留痕。
