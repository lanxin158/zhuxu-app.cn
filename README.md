# 筑序 · 施工效率驾驶舱（正式演示版）

面向项目经理、生产经理和现场管理人员的施工全过程效率管理系统。一套局域网服务器可管理多个项目，每个项目拥有独立的组织架构、账号授权与业务数据；支持新项目首次启动初始化。

## 当前能力

- 一套服务器可建立多个项目：每个项目独立登录、独立组织架构与数据空间，项目间互不可见；登录时选择项目。
- 新项目首次启动（全新数据库）自动进入“初始化向导”：建立项目并登记第一位管理员（项目经理），管理员账号密码由创建者设定。
- 项目经理可随时在项目菜单中建立新的项目系统，并指定新项目的管理员账号。
- 提供独立登录页、登录会话、保持登录和安全退出；账号与组织架构人员、岗位权限绑定，且只能在被授权的项目登录。
- 局域网多人版首次登录必须修改初始密码，新密码至少 8 位且同时包含字母和数字；改密后该账号的其他登录会话自动失效。
- 项目经理在组织架构中新增人员即自动生成登录账号：账号唯一、初始密码为登记手机号后六位、首次登录强制改密；组织架构页可维护账号（新增、编辑、禁用/启用与重置密码）。
- 服务端授权：未改密的账号不能写任何共享数据；组织架构数据仅项目经理可写入，实名制考勤仅劳资员或项目经理可写入，越权请求被拦截并写入审计记录。
- 新项目从零开始，不含演示组织与演示业务数据；离线演示版保留“云河智造中心一期”示例数据用于体验。
- 材料审批只允许当前节点指定本人操作，其他账号可查看进度但不能代办；审批操作记录账号和时间。
- 登录后直接进入“每日任务执行中心”，不再设置独立总览入口；组织架构在专门页面维护，以账号职位作为责任匹配依据。
- 进度计划分为总计划、月计划、周计划、日计划；周计划与日计划登记责任人和责任班组（责任人可多人），日计划支持设置“当日完成百分比”以适配跨多天完成的任务，并支持新建、修改和导入后更新。
- 日计划按执行日期自动归档为“8月11日计划”等日期文件夹，展开后查看当天具体任务、责任人、责任班组、完成比例和编辑入口。
- 计划导入支持 Excel、Word、PDF、图片、CSV 和 TXT，并在写入前提供可编辑的识别结果。
- 任务支持手工录入、文件识别和语音转文字；系统按任务内容匹配岗位与责任人，且可人工修正。
- 每日任务执行中心只读取所选日期的日进度计划，先逐项列出计划名称和责任人，再跟踪昨日遗留与今日执行；本周按天展示完成比例，并按所属周计划计算应完成、实际完成和提前/正常/滞后状态。
- 本周每日投入人数只读取劳资员上传的实名制打卡记录；没有考勤记录的日期明确显示“未上传”，不使用任务填报人数替代。
- 班组可提前提交需协调问题，系统持续展示提出人、责任人、最晚解决时间以及“待跟进—正在跟进—已完成”的闭环状态。
- 任务中的设计变更和施工指令带明显风险标识；弹窗直接展示技术内容、适用范围和上传原文件，并保存接收对象、确认人和确认时间。
- 侧边栏新增“技术文件”，统一共享施工图纸、设计变更、联系函和指令单，支持分类筛选、查看正文与原附件。
- 施工图按单体自动建立文件夹；打开单体文件夹后查看对应图纸，上传时记录所属单体、适用范围和原文件。
- 侧边栏新增“成控文件”，统一管理合同、经济核定单和现场工程量确认单，记录责任单位、涉及金额、工程部位、确认内容及签章原件。
- 成控文件仅项目经理及商务、成本、造价岗位可进入；局域网服务端同时限制成控数据读取、写入和附件下载，并记录越权拦截审计。
- 材料和资料保障卡只显示未闭环风险项；复试、检测报告、门禁等阻断项红色警示，普通待签字资料提示“待完善”。
- 原始信息采集继续支持文件、表格、照片、语音和手工记录，人工校核后可分发到现有业务台账。
- 所有任务均可编辑，也可按紧急或一般级别催办影响本任务的前置工序。
- 现场记录支持拍照或从相册选择多张照片，压缩后持久保存到浏览器本地数据库。
- 材料和设备分开管理，并分别登记名称、分类、品牌、规格、进出场时间、数量、使用部位和附件。
- 材料按类别汇总；合格证、见证取样和验收照片可随进场记录保存。
- 材料进场后自动通知资料员，并生成“是否取样送检、是否留存合格证”的待办事项。
- 材料与设备计划可单独新建，记录需求日期、数量、责任岗位和状态。
- 材料设备计划责任岗位从项目组织架构读取，覆盖施工员、质量员、材料员、试验员等岗位。
- 材料设备计划在要求到场前 7 天自动进入预报，临近或逾期未到场时分级提示。
- 台账登记可自动推荐或人工指定关联计划；分批到场会累计已到数量，并实时计算剩余数量。
- 材料、设备台账及计划清单均可点击查看完整详情和关联到场记录。
- 材料设备附件原文件保存到浏览器附件库；图片可直接预览，PDF可在线打开，其他文件可下载查看。
- 资料完成情况与施工进度关联，覆盖钢筋、混凝土和防水工程资料链及工序放行。
- 所有材料进场批次都会生成对应资料链，自动带入品牌、规格、数量和使用部位。
- 资料任务可查看编辑，分别保存送检委托和检测报告，并记录待送检、检测中、合格或不合格状态。
- 质量与安全检查支持编辑、巡检表上传、整改前后照片和复验闭环，统计卡片可展开具体内容。
- 组织架构页记录项目管理人员姓名、职务、管理范围及电话；现场人数由劳资员上传每日实名制考勤表更新。
- 全局“记录施工反馈”只在每日任务执行首页显示，其他页面保留各自的业务操作入口。
- 二级页面提供固定返回按钮，适配桌面、平板和手机屏幕。
- 支持晨会简报、效率建议和项目 JSON 数据导出。

## 文件识别说明

- DOCX、XLSX、CSV、TXT：在浏览器本地解析，可形成多条可编辑任务或计划。
- PDF：当前原型使用本地文本特征提取，复杂排版或扫描件需要人工校对。
- 图片：浏览器支持原生文字检测时会直接识别；不支持时生成待校对候选项。
- 语音：浏览器支持语音识别且授予麦克风权限时可直接转文字，也可粘贴转写稿后解析。

生产环境若要求稳定识别扫描 PDF、施工计划照片和嘈杂现场语音，建议接入企业 OCR、语音识别及大模型结构化服务。

## 运行方式

### 项目局域网多人试用（推荐）

1. 在作为项目服务器的电脑上双击 `启动局域网版.cmd`。
2. Windows 防火墙首次询问时，允许 Node.js 访问“专用网络”。
3. 启动窗口会显示本机和局域网登录地址。
4. 本机访问 `http://127.0.0.1:8080`；同一 Wi-Fi/局域网中的其他设备访问 `http://服务器电脑IP:8080`。
5. 当前电脑的 WLAN 地址示例为 `http://192.168.1.6:8080`，地址变化时以启动窗口显示为准。

多人版数据保存在 `data/zhuxu-lan.sqlite`，请定期备份该文件。关闭启动窗口或按 `Ctrl+C` 会停止服务，作为服务器的电脑需要保持开机和联网。

多人版支持一套服务器管理多个项目：首次启动（全新数据库）进入“初始化向导”建立第一个项目和管理员；之后项目经理可在顶栏项目菜单中建立更多项目。每个项目的每日执行反馈、协调事项、原始信息采集、技术文件、成控文件、任务、计划、材料设备台账、资料状态、审批流程、质量安全、组织架构和考勤数据完全隔离；服务器同时校验登录会话、项目授权、首次登录改密、材料审批权限、成控文件岗位权限以及组织架构/考勤写入权限，上传附件由服务器统一保存并可跨设备查看。

### 本机离线演示

直接使用浏览器打开 `index.html`，无需启动服务。该模式的数据只保存在当前浏览器中，不与其他人同步。

若只需临时静态预览，可在此目录启动静态文件服务：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 开发基线

### 环境要求

- Windows 10/11；
- Node.js 24 或更高版本（服务端使用内置 `node:sqlite`）；
- npm；
- Google Chrome，默认安装位置为 `C:\Program Files\Google\Chrome\Application\chrome.exe`。

首次获取代码后安装锁定版本的开发依赖：

```powershell
npm ci
```

启动局域网服务：

```powershell
npm start
```

运行完整开发基线检查：

```powershell
npm test
```

完整检查包含 JavaScript 语法、桌面和移动端离线流程、材料审批与隐蔽验收、信息采集与业务分发，以及局域网多账号登录、共享状态和服务端审批权限。局域网测试会自动创建并清理独立的临时数据库，不会改动 `data/zhuxu-lan.sqlite`。

测试生成的 `qa-*.png` 截图、`node_modules/`、npm 缓存、运行数据库和上传附件均已加入 `.gitignore`。切换 ChatGPT、Codex 或 DeepSeek 前，应更新 [HANDOFF.md](HANDOFF.md)，并只交接项目文件、普通文本和稳定 JSON，不传递供应商原始响应对象。

## 登录说明

- 局域网多人版支持多个项目，登录前先在“登录项目”下拉中选择要进入的项目。
- 新项目首次启动（全新数据库）不显示登录页，而是显示“初始化向导”：填写项目名称、项目编码和管理员（项目经理）信息，管理员密码由创建者自行设定。
- 项目经理登录后，在“组织架构 → 账号管理”中新增人员即自动生成登录账号：账号由创建者指定且全局唯一，初始密码为该人员登记手机号的后六位。
- 局域网多人版首次登录会强制修改初始密码：新密码至少 8 位且同时包含字母和数字；修改成功后旧密码失效。
- 账号的新增、编辑、禁用/启用和重置密码由项目经理在“组织架构”页的账号管理中完成；重置后该账号恢复为初始密码并需再次改密。
- 只有被项目经理加入当前项目组织架构的账号才能登录该项目，其他账号即使密码正确也会被拒绝。
- 左侧栏底部可退出当前账号；退出后必须重新输入账号和密码登录。

离线演示版（直接打开 `index.html`）保留“云河智造中心一期”示例账号与数据用于体验，密码校验与数据保存在浏览器本机，不强制改密、不支持多项目。局域网多人版已由服务端完成密码哈希（scrypt 加盐）、会话管理、项目授权、首次登录改密、账号管理与岗位权限校验，并记录审计留痕。
