# 筑序 · 阿里云域名 + 备案 + HTTPS 上线手册

适用：阿里云 ECS（大陆节点）、有 50 人使用、需要正式对外提供 HTTPS 访问。
成员无需安装任何 App，直接用手机/电脑浏览器打开网址登录。

## 一、总体流程与时间

| 步骤 | 内容 | 预计时间 |
|---|---|---|
| 1 | 购买域名并实名认证 | 1 天 |
| 2 | ICP 备案 | 2~3 周 |
| 3 | 服务器部署筑序 | 1 天 |
| 4 | 域名解析 + 安全组放行 | 10 分钟 |
| 5 | Caddy 自动 HTTPS | 10 分钟 |

建议顺序：先买域名并提交备案，备案审核期间把服务器部署好、数据导入好；备案通过后当天就能上线。

## 二、第 1 步：购买域名（阿里云）

1. 登录阿里云控制台 → 域名注册（万网）；
2. 搜索并注册一个域名，推荐 .com 或 .cn，例如 zhuxu-xxx.com；
3. 完成域名实名认证（个人用身份证，企业用营业执照）；
4. 购买 1 年即可，费用一般几十元。

## 三、第 2 步：ICP 备案

1. 前提：服务器必须是阿里云大陆节点 ECS（备案要求服务器在阿里云，且需生成备案服务码）；
2. 打开阿里云控制台 → ICP 备案，按向导填写：
   - 主办者信息：个人身份证 / 企业营业执照；
   - 网站信息：网站名称、域名、服务内容（选“企业门户/工具类”）；
   - 网站负责人：姓名、手机号（需接收核验短信/电话）；
   - 人脸核验：按提示完成拍照或小程序核验；
3. 提交后等待管局审核，一般 2~3 周；
4. 备案期间，阿里云会拦截该服务器 80/443 端口的对外访问，属正常现象；
5. 备案通过后会收到备案号（如 京ICP备xxxxxxxx号）。

合规提醒：
- 网站首页底部需展示备案号，并链接到 https://beian.miit.gov.cn；
- 备案通过后 30 天内，到“全国互联网安全管理服务平台”办理公安备案。

## 四、第 3 步：服务器部署筑序

1. ECS 建议 2核4G、60GB SSD、Ubuntu 22.04/24.04；
2. 用 WinSCP 把项目上传到 /opt/zhuxu/（不要传本机 data 目录和 .git）；
3. SSH 登录服务器：

   cd /opt/zhuxu/deploy/aliyun
   bash scripts/deploy.sh

4. 本机验证：curl http://127.0.0.1:8080/api/health 应返回 {"ok":true,...}。

## 五、第 4 步：域名解析

1. 阿里云控制台 → 域名 → 解析设置；
2. 添加 A 记录：
   - 记录类型：A
   - 主机记录：@（或 www，若要用 www 前缀则再加一条）
   - 记录值：服务器公网 IP
3. 解析生效后用 ping 或 https://tool.chinaz.com/dns 验证。

## 六、第 5 步：安全组放行

阿里云控制台 → ECS → 安全组 → 添加入方向规则：

| 协议 | 端口 | 来源 | 用途 |
|---|---|---|---|
| TCP | 22 | 你公司的固定IP（推荐） | SSH 管理 |
| TCP | 80 | 0.0.0.0/0 | HTTP 跳转/证书验证 |
| TCP | 443 | 0.0.0.0/0 | HTTPS 正式访问 |

不要放行 8080 到公网，筑序服务只允许服务器本机访问。

## 七、第 6 步：一键配置 Caddy（自动 HTTPS）

SSH 登录服务器执行：

    cd /opt/zhuxu/deploy/aliyun
    bash scripts/caddy-setup.sh 你的域名

脚本会自动：
1. 安装 Caddy（官方源）；
2. 生成 /etc/caddy/Caddyfile（含安全响应头、压缩、访问日志）；
3. 校验配置并启动；
4. 自动申请并续期 HTTPS 证书。

如果脚本提示证书申请失败，多半是域名解析未生效或 80 端口没放行，按上面第五、六步检查后重试：
systemctl restart caddy

## 八、第 7 步：上线验证

1. 浏览器打开 https://你的域名，应出现筑序登录页；
2. 用组织架构账号登录（初始密码为手机号后六位）；
3. 建议在手机 4G/5G 网络下再试一次，确认不依赖公司网络；
4. 登录后上传一张照片，到服务器 data/uploads 确认文件已保存。

## 九、成员使用说明（直接转发给成员）

- 打开浏览器，输入 https://你的域名；
- 输入你的账号和密码登录；
- 无需安装任何软件，手机电脑都可以；
- 在工地、家里、外地都能用，只要有网。

## 十、常见问题

Q：备案期间能不能先访问？
A：备案未通过前，大陆服务器 80/443 会被拦截。如果人员都在公司固定网络，可临时把安全组放行 8080（来源仅限公司出口 IP），访问 http://公网IP:8080，并把 .env 里 ZHUXU_COOKIE_SECURE 改为 0 后重启容器。这只能临时用，不建议长期。

Q：Caddy 证书多久续期？
A：Caddy 自动续期，无需人工处理。

Q：换服务器或换公网 IP？
A：改域名解析指向新 IP，Caddy 会自动重新申请证书；注意新服务器也要完成备案关联。

Q：HTTPS 打不开但 http 能开？
A：确认安全组放行 443，且域名解析正确；执行 systemctl status caddy 查看错误。
