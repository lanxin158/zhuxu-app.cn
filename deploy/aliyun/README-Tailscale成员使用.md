# 筑序 · Tailscale 成员使用说明（手机 / 电脑）

本说明适用于服务器已按《README-阿里云部署.md》完成 Tailscale 组网后的所有成员。

## 一、你需要准备的

1. 服务器管理员提供给你的访问地址，格式类似：
   https://zhuxu-server.tailXXXX.ts.net
2. 你的筑序登录账号（组织架构里的账号）和初始密码（登记手机号后六位）。

## 二、手机（iOS / Android）

1. 在应用商店搜索并安装 Tailscale；
2. 打开 App，用管理员发给你的方式登录：
   - 方式 A：点击管理员发来的邀请链接，直接加入；
   - 方式 B：使用与服务器同一个 Tailscale 账号登录；
3. 登录后保持 Tailscale 开启（绿色已连接状态）；
4. 打开手机浏览器，输入访问地址，进入筑序登录页；
5. 输入你的账号和密码登录。

## 三、电脑（Windows）

1. 到 https://tailscale.com/download 下载 Windows 客户端并安装；
2. 登录方式同上（邀请链接或同一账号）；
3. 任务栏出现 Tailscale 图标并显示已连接；
4. 打开浏览器访问服务器管理员给的 HTTPS 地址；
5. 输入你的账号和密码登录。

## 四、常见问题

Q：提示“无法访问此网站 / 连接超时”？
A：先确认 Tailscale 已连接（手机 App 或电脑任务栏显示已连接）；再确认地址没有拼错。

Q：登录后一直停在登录页？
A：必须使用 https:// 地址访问；如果用 http:// 访问，系统会认为不安全而无法保持登录。

Q：访问地址需要发给所有人吗？
A：地址只在公司内部使用，不要发到互联网；账号密码也不要告诉别人。

Q：我是新成员，没有账号怎么办？
A：让管理员在“组织架构”里添加你（账号、姓名、职务、手机号），初始密码为你登记手机号的后六位。

## 五、安全提醒

- Tailscale 只允许加入你公司网络的设备访问服务器，其他人即使拿到地址也无法打开；
- 不要在公共场所的电脑上保存“保持登录”；
- 发现账号异常立即联系管理员。
